# Outcome, not mechanism

Say what you want to be true when the job is done. Do not say which steps or tools to use.

- Mechanism: "make a new folder copy of the project and switch to it."
- Outcome: "I want to try this change without risking my working version."

The second one lets the agent pick the cleanest way, which is often better than the one you had in mind. If it picks something different from what you pictured, ask why. The answer is usually worth learning.

Mechanism is still right when you truly need that exact thing. Just notice which one you are doing.

Used in [What I learned](../Guide/04-what-i-learned.md). Related: [Plain plan](Plain-Plan.md).

> **Aub:** Half the time I name a tool I half remember, and the agent had a better one built in.
