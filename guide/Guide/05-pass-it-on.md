# Step 5: Pass it on

The best way to learn this is to teach it.

1. Pick one person who has an idea and does not code.
2. Send them this repo. Tell them to start at [Maps/Start.md](../Maps/Start.md).
3. Sit with them for [Step 1](01-you-and-a-buddy.md). Only watch. Do not type for them.
4. When they get stuck, ask "what did you expect to see?" before you answer.

You are done when they leave Step 1 with a plain plan in their own words.
