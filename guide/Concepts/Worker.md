# Worker

A worker is an agent that does one small job for a [Lead](Lead.md). It has one goal, a clear out-of-scope list, and a report to write at the end.

Rules for a worker:

- Do only the job. Write down anything else you notice, but do not fix it.
- End with a report that has raw output. See [Proof, not prose](Proof-not-Prose.md).
- Do not edit planning docs. Put suggested changes in the report. The Lead files them.
- If the job cannot be done as written, stop and say so. Stopping is a normal result.

**VibeSquad:** workers show as cards under their Lead, named after their job.

In any other agent, a worker is a sub-agent, or a fresh chat given one job and the project's rules file.
