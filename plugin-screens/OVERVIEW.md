VibeSquad screens shows your VibeSquad Squads inside Paseo: each Squad, its feature lanes, and how many Leads, Buddies and workers each lane has, with needs-you flags.

It is read-only. Agents come from Paseo itself. Squad and lane names come from the VibeSquad server running on the same machine as the Paseo daemon (`http://127.0.0.1:4180`, or `VIBESQUAD_PORT`).

The screen is off by default. Turn it on under Settings, Plugins, VibeSquad screens. While it is off, the plugin returns no VibeSquad data to any client.
