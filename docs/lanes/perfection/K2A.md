## Fix (server/compact-step.mjs)
- C1/C3: fresh runner status before sending. If the agent is running or queued, return skipped busy: the lead ladder defers and the next idle re-evaluates.
- C2: `sendAgentPrompt` now returns the runner's `{ queued }` (runner-backend). While queued, a turn_ended before turn_started is ignored. The attempt clock starts at turn start, and the queue wait has its own 10 min cap.
- C1/C3/C4 residual: a no-boundary turn end retries /compact alone once the runner shows idle with nothing queued, up to 3 sends. A late boundary (CLI-queued steer) counts as ok.
- C1 late boundary: when the runner log shows the /compact input landed while the turn was already running (`compactLanding` = steered), the retry first waits up to 240 s for the CLI to run the held /compact as its own turn. It stops early if the process is parked or exits. Without this, an immediate re-send compacted twice and skewed the adapter's open-turn count (the CLI runs the held /compact while the runner shows idle).
- C5: per-attempt timeout is 240 s from turn start.
- Metric: ` reason=<no-boundary|turn-failed|send|label-write|turn|queue>` and ` attempts=<n>` are appended after tokens=, so the providers-catalog regexes are unchanged.

## Follow-ups (not in K2a)
- @bug: reduceTurn emits turn_ended(completed) when a queued agent is parked (parked→idle while awaiting). Other turn_ended consumers (digests, wakes) may see a turn that never ran.
- @bug: the claude adapter cannot see a steer the CLI runs as its own later turn (a `/compact` turn emits no assistant/user line before `compact_boundary`), so the runner shows idle and may park the process mid-compaction. K2a only waits for it; the adapter/park side is not fixed here.
- @bug: runner.send coalesces later inputs into a queued `/compact` job, which makes the wake text the compact focus (seen on rn-8ad0fba454e9). The fix is to never coalesce into or behind a /compact job.
- Residual (no runner dequeue API): a `/compact` still queued at the 10 min queue cap stays in the runner queue while the ladder falls through to handoff, so the Wrap-up can coalesce into it. Observed queue waits were 74-399 s, under the cap.
