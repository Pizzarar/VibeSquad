# Notebook

Raw notes live here: diary, brainstorms, half-ideas. They are private. Git ignores everything in this folder except this file.

When an idea holds up, it gets distilled into [ROLO](../ROLO.md) or a note in [Concepts](../Concepts/Buddy.md). Those are public.

That is the same loop as the method: riff first, then keep what is worth keeping.

The loop is written up in [Notebook (concept)](../Concepts/Notebook.md).
