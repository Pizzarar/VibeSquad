# Start

The guide, in order.

The flow: install your provider and sign in, run the VibeSquad installer, add this folder as a team in VibeSquad, and the Brainstorm chat (the Buddy) runs [START_HERE](../START_HERE.md).

1. Read [ROLO](../ROLO.md) first. It is one page.
2. [Everybody can vibe](../Guide/00-everybody-can-vibe.md)
3. [You and a Buddy](../Guide/01-you-and-a-buddy.md) (Riff)
4. [Lead and workers](../Guide/02-lead-and-workers.md) (Organize)
5. [Back to you](../Guide/03-back-to-you.md) (Own)
6. [What I learned](../Guide/04-what-i-learned.md)
7. [Pass it on](../Guide/05-pass-it-on.md)

Loop runs through every step.

> **Aub:** Just build. All I've ever done is ask, "I wonder if I can do this?" and then try. You'll hit walls constantly, and things will break constantly. But every round, you get better at understanding how it thinks *with* you.
